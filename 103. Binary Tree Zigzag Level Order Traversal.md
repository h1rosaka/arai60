```py
class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if root is None:
            return []
        # ansに足す時だけひっくり返せば良い
        reverse = False
        ans = []
        node_in_this_level = [root]
        while node_in_this_level:
            node_vals = []
            next_nodes = []
            for node in node_in_this_level:
                node_vals.append(node.val)
                if node.left:
                    next_nodes.append(node.left)
                if node.right:
                    next_nodes.append(node.right)
            if reverse:
                node_vals.reverse()      
            ans.append(node_vals)
            node_in_this_level = next_nodes
            reverse = not reverse
        return ans
```

        - 左右両端を交換 → 一マスずつ内側にしてまた交換 →　以下繰り返し
        - 計算量は時間がO(N)、空間がO(1)
    - ノード数は最大2000なので、reverseするときは最大1000入りうるが、余裕。

```py
class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if root is None:
            return []
        reverse = False
        zigzag_order = []
        node_in_this_level = [root]
        while node_in_this_level:
            node_vals = deque([])
            next_nodes = []
            for node in node_in_this_level:
                if not reverse:
                    node_vals.append(node.val)
                else:
                    node_vals.appendleft(node.val)
                if node.left:
                    next_nodes.append(node.left)
                if node.right:
                    next_nodes.append(node.right)   
            zigzag_order.append(list(node_vals))
            node_in_this_level = next_nodes
            reverse = not reverse
        return zigzag_order
```
