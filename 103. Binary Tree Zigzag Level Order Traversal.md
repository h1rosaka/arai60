# STEP 1 自力で解く。
```py
class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if root is None:
            return []
        # ansに足す時だけひっくり返せば良い
        reverse = False
        ans = []
        level_nodes = [root]
        while level_nodes:
            node_vals = []
            next_level_nodes = []
            for node in level_nodes:
                node_vals.append(node.val)
                if node.left:
                    next_level_nodes.append(node.left)
                if node.right:
                    next_level_nodes.append(node.right)
            if reverse:
                node_vals.reverse()      
            ans.append(node_vals)
            level_nodes = next_level_nodes
            reverse = not reverse
        return ans
```
- 所要時間　50分
    - 最初はリストを逆順に見たり、左右の子を足す順番を逆にしたり、複雑なことをやろうとして失敗して時間を溶かした

    - ノード数は最大2000なので、reverseするときは最大1000入りうるが、余裕。

```py
class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if root is None:
            return []
        going_left = False
        zigzag_order = []
        level_nodes = [root]
        while level_nodes:
            node_vals = deque([])
            next_level_nodes = []
            for node in level_nodes:
                if not going_left:
                    node_vals.append(node.val)
                else:
                    node_vals.appendleft(node.val)
                if node.left:
                    next_level_nodes.append(node.left)
                if node.right:
                    next_level_nodes.append(node.right)   
            zigzag_order.append(list(node_vals))
            level_nodes = next_level_nodes
            going_left = not going_left
        return zigzag_order
```

# STEP3　　3回連続でエラーなしで解けるまで解く
```py
class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if root is None:
            return []

        level_nodes = [root]
        going_left = False
        zigzag_order = []
        while level_nodes:
            node_vals = deque()
            next_level_nodes = []
            for node in level_nodes:
                if not going_left:
                    node_vals.append(node.val)
                else:
                    node_vals.appendleft(node.val)
                if node.left:
                    next_level_nodes.append(node.left)
                if node.right:
                    next_level_nodes.append(node.right)
            zigzag_order.append(list(node_vals))
            level_nodes = next_level_nodes
            going_left = not going_left
        return zigzag_order
```
6:30, 6:20, 5:18
- 計算量
    - 時間: O(N)
        - 全てのノードを一つずつ処理。処理ごとの計算量はO(1)
            - list(node_vals)はそのレベルのノードの数分コピーが発生するが、全体で見ると各ノードにつき1回ずつ
    - 空間:O(N)
        - level_nodes: O(N)
        - next_level_nodes: O(N)
        - zigzag_order: O(N)
        - node_vals: O(N)
        - list(node_vals) :  O(N)
