# STEP 1 自力で解く。
```py
class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        height = len(obstacleGrid)
        width = len(obstacleGrid[0])
        grid = [[0] * width for _ in range(height)]
        for row in range(height):
            for col in range(width):
                if obstacleGrid[row][col] == 1:
                    continue
                if row == 0 and col == 0:
                    grid[row][col] = 1
                    continue
                if row == 0:
                    grid[row][col] = grid[row][col - 1]
                elif col == 0:
                    grid[row][col] = grid[row - 1][col]
                else:
                    grid[row][col] = grid[row - 1][col] + grid[row][col - 1]
        return grid[-1][-1]
```
- 最初書いた時は、左端と上端に石が来るケースを考慮しておらずWAになった。
- grid[row][col] = 1は for文の外で書いても良いかもしれない

```py
class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        OBSTACLE = 1
        height = len(obstacleGrid)
        width = len(obstacleGrid[0])
        num_paths = [0] * width
        for row in range(height):
            for col in range(width):
                if obstacleGrid[row][col] == OBSTACLE:
                    num_paths[col] = 0
                    continue
                if row == 0 and col == 0:
                    num_paths[col] = 1
                    continue
                if col > 0:
                    num_paths[col] += num_paths[col - 1]
        return num_paths[-1]
```

# STEP3　　3回連続でエラーなしで解けるまで解く
```py
class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        height = len(obstacleGrid)
        width = len(obstacleGrid[0])
        num_paths = [[0] * width for _ in range(height)]
        OBSTACLE = 1
        if obstacleGrid[0][0] == OBSTACLE:
            return 0
        num_paths[0][0] = 1
        for row in range(height):
            for col in range(width):
                if obstacleGrid[row][col] == OBSTACLE:
                    continue
                if row > 0:
                    num_paths[row][col] += num_paths[row - 1][col]
                if col > 0:
                    num_paths[row][col] += num_paths[row][col - 1]
        return num_paths[-1][-1]
```
-  num_paths[0][0]の定義はforループの中で何度も条件判定するのが無駄だと感じたので、外に出してみた。obstacleGrid[0][0] == OBSTACLEの条件判定が余計に追加されたので、前の方がシンプルだったかも？
