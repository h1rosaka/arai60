# STEP 1 自力で解く。
```py
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:

        def helper(root, low, high):
            if root is None:
                return True
            if not (low < root.val < high):
                return False
            return (helper(root.left, low, min(high, root.val)) and 
                    helper(root.right, max(low, root.val), high))

        return helper(root, - math.inf, math.inf)

```
- 所要時間 30 min
- 最初、親と子の関係だけ判定するコードを書きWAになった。親の親や、その先の親含めて、全て自分との大小関係が成立していないといけない。つまり、今までの親たちがどうだったかによって、自分がokな範囲が決まる
- minやmaxは要らなかった。
    - `if not (low < root.val < high):`で確認した段階でmin/maxの結果決まってる
    - 左部分木がどこまで大きくなってOKかの最大値は、rootノードの値-1(それはそう)
-  helperの引数のrootはnodeの方がわかりやすかった。

```py
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        if root is None:
            return False
        stack = [(root, - math.inf, math.inf)]
        while stack:
            node, low, high = stack.pop()
            if not (low < node.val < high):
                return False
            if node.right:
                stack.append((node.right, node.val, high))
            if node.left:
                stack.append((node.left, low, node.val))
        return True
```

```py
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        def append_left_nodes(node, nodes):
            while node is not None:
                nodes.append(node)
                node = node.left

        nodes_to_check = []
        append_left_nodes(root, nodes_to_check)
        lower_bound = - inf
        while nodes_to_check:
            current = nodes_to_check.pop()
            if current.val <= lower_bound:
                return False
            lower_bound = current.val
            if current.right:
                if current.right.val <= current.val:
                    return False
                append_left_nodes(current.right, nodes_to_check)
        return True
```
- こちらは"魔法の一筆書き"のイメージ。左からぐるっと木を囲む。

```py
# inorder traversal(再帰) 最初に全てのノードをinorderでソートしたリストを作ってからそれを探索する。
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        def inorder_sort(node, nodes):
            if node is None:
                return
            inorder_sort(node.left, nodes)
            nodes.append(node)
            inorder_sort(node.right, nodes)

        inordered_nodes = []
        inorder_sort(root, inordered_nodes)
        prev_value = - math.inf
        for node in inordered_nodes:
            if node.val <= prev_value:
                return False
            prev_value = node.val
        return True
```

generator
```py
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        def inorder_sort(node):
            if node is None:
                return
            yield from inorder_sort(node.left)
            yield node
            yield from inorder_sort(node.right)

        prev_value = - math.inf
        for node in inorder_sort(root):
            if node.val <= prev_value:
                return False
            prev_value = node.val
        return True

```
- 全部メモリに持たなくて良いのでお得。
- inorder_sort()が呼ばれるたびに、新たなGeneratorインスタンスが作られている
    - 左の部分木が終わると、そこにあったgeneratorたちは消える
        - 左下に向かって一直線で長く伸びてる箇所があると、たくさんのgeneratorを同時に抱える
- yield from

```py
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        def inorder_sort(node):
            if node is None:
                return
            yield from inorder_sort(node.left)
            yield node
            yield from inorder_sort(node.right)

        prev_val = - math.inf
        for node in inorder_sort(root):
            if node.val <= prev_val:
                return False
            prev_val = node.val
        return True
```

- 計算量
    - 時間:O(N)
        - 結局各ノードを一個ずつ出すので。
