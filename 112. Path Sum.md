# STEP 1 自力で解く。

最初こちらを書いた
- treeの途中で合計がtargetになってもTrueになってしまう。
- targetがマイナスの場合を考慮していない

```py
# WAになります
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
            if root is None:
                return False
        
            if targetSum - root.val == 0:
                return True
            if targetSum - root.val < 0:
                return False

            return (self.hasPathSum(root.left, targetSum - root.val) or 
                    self.hasPathSum(root.right, targetSum - root.val))

```

修正したもの
```py
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
            if root is None:
                return False
        
            if root.left is None and root.right is None:
                return targetSum - root.val == 0 
        
            return (self.hasPathSum(root.left, targetSum - root.val) or 
                    self.hasPathSum(root.right, targetSum - root.val))
```
- 所要時間　10分ほど
- 再帰の終了条件をちゃんと日本語にしてから書いたらミスに気づけたかもしれない。反省。「合計がtargetになったら」ではなく「末端にたどり着いたら」であった。
- マイナスの場合の考慮が抜けていたのも痛い。書き始める前に確認が必要。





# STEP2 読みやすくする＆他の人の解法を見る
stackでも書いてみる
```py
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
        stack = [(root, targetSum)]
        flag = False
        while stack:
            node, target = stack.pop()
            if node is None:
                continue
            if node.left is None and node.right is None:
                if node.val == target:
                    flag = True
            stack.append((node.left, target - node.val))
            stack.append((node.right, target - node.val))
        return flag

```
- https://github.com/SuperHotDogCat/coding-interview/pull/37#discussion_r1665891252
    - 確かに引き算を先にして、rest == 0の方がわかりやすかったかも。target - node.val　も2回書かなくて良くなるし。
    - flagとか必要なかった。Trueの時はreturn Trueで、最終行はreturn Falseにしておけば十分だった。
        - 再帰の方のor条件を再現しようとして余計な手間を増やしていた。
        - さらにいうとこちらの方が、見つかり次第終了できるのでお得。

# STEP3　　3回連続でエラーなしで解けるまで解く
```py
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
        if root is None:
            return False
        rest = targetSum - root.val
        if root.left is None and root.right is None:
            if rest == 0:
                return True
        return self.hasPathSum(root.left, rest) or self.hasPathSum(root.right, rest)
```
3:50, 2:39, 1:59

- 計算量
    - 時間O(N)
        - 1つのノードチェックするのはO(1)で、最悪全ノードチェックするので
    - 空間O(N)
        - ~~再帰の深さ分のスタックメモリO(logN)~~
            - 訂正：二分木とは限らないので、Nかもしれない
        - 1回あたり追加で必要なのはrestのO(1)
