# 問題タイトル
[322. Coin Change](https://leetcode.com/problems/coin-change/description/)



# STEP 1 自力で解く。
```py
def coinChange(self, coins: List[int], amount: int) -> int:
    num_necessary_coins = [math.inf] * (amount + 1)
    num_necessary_coins[0] = 0
    for i in range(1, amount + 1):
        for coin in coins:
            if i < coin:
                continue
            num_necessary_coins[i] = min(num_necessary_coins[i - coin] + 1, num_necessary_coins[i])

    if num_necessary_coins[-1] == math.inf:
        return -1
    return num_necessary_coins[-1]
```
- 何度かエラーやWAになった。
    - -1を返すパターンの記述忘れ
    - num_necessary_coins[0]の初期化忘れ
    - i < coin　の場合のアクセスしたい[i - coin]のインデックスがない
- minのところは一行が長いので、2行にした方が良さそう。
- num_necessary_coins[amount]の方がわかりやすいかもしれない。

    ```py
    class Solution:
        def coinChange(self, coins: List[int], amount: int) -> int:
            # BFSで1枚ずつコインを足しながら見ていく。amountの金額になったら終了
            # next_amountが過去すでにより少ない枚数で実現されていたら、無駄なのでキューにキューにいれない
            amount_and_num_coins = deque([(0, 0)])
            found_amount = set()
            while amount_and_num_coins:
                current_amount, num_coins = amount_and_num_coins.popleft()
                for coin in coins:
                    if current_amount == amount:
                        return num_coins
                    if current_amount > amount:
                        continue
                    next_amount = current_amount + coin
                    if next_amount in found_amount:
                        continue
                    found_amount.add(next_amount)
                    amount_and_num_coins.append((next_amount, num_coins + 1))
            return -1
    ```

# STEP3　　3回連続でエラーなしで解けるまで解く
再帰
```py
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        @cache
        def num_necessary_coins(amount):
            if amount < 0:
                return math.inf
            if amount == 0:
                return 0
            return min(num_necessary_coins(amount - coin) + 1 for coin in coins)

        if num_necessary_coins(amount) == math.inf:
            return -1
        return num_necessary_coins(amount)
```

- 計算量(キャッシュあり)
    - amount = N, coinの種類数＝M, coinの中の最小価格をvとする
    - 時間:O(NM)
        -  num_necessary_coins(x) は 各 x (0～N) について1回だけ 計算される
            - 1回あたりM回のnum_necessary_coinsを呼び出す
    - 空間:
        - cacheがO(N)
        - 再帰のスタックの深さが最大N/vなのでO(N)

- 計算量(キャッシュなし)
    -  amount = N, coinの種類数＝M, coinの中の最小価格をvとする
    - 時間　
        - M^(N/v)なので、O(M^N)
    - 空間
        - 再帰のスタックの深さが最大N/vなのでO(N)
