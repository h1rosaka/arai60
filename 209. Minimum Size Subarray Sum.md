# 問題タイトル
[209. Minimum Size Subarray Sum](https://leetcode.com/problems/minimum-size-subarray-sum/description/)


# STEP 1 自力で解く。
```py
class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        min_len = math.inf
        left = 0
        total = 0
        for right in range(len(nums)):
            total += nums[right]
            if total < target:
                continue
            while target <= total:
                min_len = min(min_len, right - left + 1)
                total -= nums[left]
                left += 1
        if min_len == math.inf:
            return 0
        return min_len
```
- targetを超えるまで、rightを一つずつ増やして足す
- targetを超えたら、
    - 長さを測って、minと比較
    - 左から一つ削ってみる
    - target未満になるまで繰り返し。未満になったら、今のrightでは無理なので、またrightを動かす
- 全てのマスにおいて、そこがrightになった時の最短記録を確認し、min_lenと比較しているので、全パターン確認できている。
計算量
- nums.length = Nとすると forループがO(N)
    - ループの中の1回あたりはパッとわかりにくい
    - →ただ、whileループの中身が実行されるの回数は、`left += 1`が実行される回数であって、最大でもN回
    - 結局計算量としては、whileループの中身が実行される回数のオーダーで良いのでO(N)

    - iマス目までの累積和を全て計算後、累積和同士の引き算で、subarrayの合計を出す。
    - マス目iから最短でtargetを超えられる要素数を見つけたら、マス目iについては探索終了。次のマスへ。
    - targetを超えられる要素数を見つけるときに、累積和が単調増加であることを意識すると、二分探索ができる。

二分探索で探すコード
```py
class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        # nums[i:j]の和をprefix_sums[j] - prefix_sums[i]で表すために、何も足していないことを表すprefix_sumをひとつ追加で作っている
        # prefix_sums[k] : sum(nums[0:k])つまり、「nums の先頭から k 個分の和」(kの一つ手前のindexまでのものの累積和)
        prefix_sums = [0] * (len(nums) + 1) 
        prefix_sums[0] = 0
        for i in range(len(nums)):
            prefix_sums[i + 1] = nums[i] + prefix_sums[i]

        min_len = inf
        for i in range(len(nums)):
            target_prefix_sum = target + prefix_sums[i]
            # ここで得られる target_index は：
            #   「i を左端としたとき、条件を満たす最短部分配列の
            #    右端 j（ただし j は prefix_sums の index）」
            target_index = bisect.bisect_left(prefix_sums, target_prefix_sum)
            if target_index == len(prefix_sums):
                break
            min_len = min(min_len, target_index - i)

        if min_len == inf:
            return 0
        return min_len
```
