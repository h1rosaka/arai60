# STEP 1 自力で解く。

```py
class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        set1 = set(nums1)
        set2 = set(nums2)
        intersection = []
        for item in set1:
            if item in set2:
                intersection.append(item)
        return intersection
```

マージソート風
```py
class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        # ソート済みだった想定の場合を再現
        nums1.sort()
        nums2.sort()

        commons = []
        # 左から一つずつ見ていって、一致してなかったら小さい方を一つ右へ
        i = j = 0
        while i < len(nums1) and j < len(nums2):
            if nums1[i] < nums2[j]:
                i += 1
                continue
            if nums1[i] > nums2[j]:
                j += 1
                continue
            # 一致したらcommonsへ格納しつつ、同じものを格納しないように同じ数字が続く限りスキップ
            common = nums1[i]
            commons.append(common)
            while i < len(nums1) and nums1[i] == common:
                i += 1
            while j < len(nums2) and nums2[j] == common:
                j += 1

        return commons

```



# STEP3　　3回連続でエラーなしで解けるまで解く
二分探索風
```py
class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        def check_existence(target: int, nums: List[int]) -> bool:
            left = 0
            right = len(nums)
            while right - left > 1:
                mid = (left + right) // 2
                if nums[mid] <= target:
                    left = mid
                else:
                    right = mid

            return nums[left] == target

        if len(nums1) > len(nums2):
            larger_nums = nums1
            smaller_nums = nums2
        else:
            larger_nums = nums2
            smaller_nums = nums1

        larger_nums.sort()
        smaller_nums_set = set(smaller_nums)
        commons = []
        for num in smaller_nums_set:
            if check_existence(num, larger_nums):
                commons.append(num)

        return commons

```
10:20, 約7分、5:20

計算量
- 大きい方の要素数をn、小さい方をmとする
- 時間: O(mlogn)
    - (ソート(ただしこれは実施済みとして問題に与えられる想定): O(nlogn))
    - smaller_nums_setの作成: O(m)
    - forループ: O(mlogn)
        - ループがm回
        - 1回あたり、check_existence()なので、O(logn)
- 空間: O(m + k)
    - (ソート(ただしこれは実施済みとして問題に与えられる想定): O(n))
    - smaller_nums_setの作成: O(m)
    - commons: O(k)(k =  共通要素の数)
