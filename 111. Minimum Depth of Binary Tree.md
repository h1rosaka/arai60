# 問題タイトル
[111. Minimum Depth of Binary Tree](https://leetcode.com/problems/minimum-depth-of-binary-tree/description/)




# STEP 1 自力で解く。
BFS
```py
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return 0 

        node_and_depth = deque([(root, 1)])
        while node_and_depth:
            node, depth = node_and_depth.popleft()
            if node.right is None and node.left is None:
                return depth
            if node.right is not None:
                node_and_depth.append((node.right, depth + 1))
            if node.left is not None:
                node_and_depth.append((node.left, depth + 1))


```

 - 一つ前のmaxの時はこれで書けたが、minでこれをやると、片方しか子供がいなかった時、いなかった方の返り値の0を採用してしまう。

こちらはACになる。
```py
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return 0
        # 両方ない時(実は片方ない時に含まれるので、なくてもOK)
        # if root.left is None and root.right is None:
        #     return 1

        # 片方ない時(※両方ないパターンも含む)
        if root.left is None:
            return 1 + self.minDepth(root.right)
        if root.right is None:
            return 1 + self.minDepth(root.left)

        # 両方ある時
        return 1 + min(self.minDepth(root.left), self.minDepth(root.right))
```
- 再帰の部下が返した長さが0だったら、それを採用してはいけないので、特別なケアが必要だった。
- 今の実装は`if root.left is None:`の中に両方ないパターンも入っていて少し気持ち悪いような気もするが、"両方ない時"を書くのと書かないのはどちらが良いのだろうか。

```py
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return 0
        node_and_depth = deque([(root, 1)])
        while node_and_depth:
            node, depth = node_and_depth.popleft()
            if node.left is None and node.right is None:
                return depth
            if node.left is not None:
                node_and_depth.append((node.left, depth + 1))
            if node.right is not None:
                node_and_depth.append((node.right, depth + 1))
```
