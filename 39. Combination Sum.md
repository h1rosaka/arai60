# STEP 1 自力で解く。
```py
class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        """
        ▶︎書く前に考えたことのメモ
        まさにバックトラッキングの問題
        [2,3,6,7]なら、最初に4本枝伸ばす。
        同じ組み合わせを見てしまうと勿体無いから、最後に足した数字と同じかそれ以上しか足せないことにする？
            targetを超えちゃったら終了　targetだったら保存して終了


        ※↓ 以下STEP1の時に考えたことが書いてありますが、STEP2を通して誤りだと判明しました。
        計算量は
            ソートO(N)
                - Nの最大値は30
            再帰
                木の中のノード数は、末端の数から大体もとまる
                2分木の時が、末端の数に対して最も多くなり、2N-1
                今、末端の数は150以下なので、最大でも300.
                一つのノードの中の処理は、sum()なのでO(N)で、最大30.
                30*300= 9000
                1分以内に十分終わる。
        """
        sorted_candidates = sorted(candidates)　# step2で判明したが、実はソート必要なかった
        stack = [([], 0)] # (chosen_nums,index)
        result = []
        while stack:
            chosen_nums, index = stack.pop()
            if sum(chosen_nums) > target:
                continue
            if sum(chosen_nums) == target:
                result.append(chosen_nums)
                continue
            for i in range(index, len(candidates)):
                stack.append((chosen_nums + [sorted_candidates[i]], i))
        return result
```

- stackではなく、中に何を入れているのかわかりやすい名前にした方が読みやすいとのこと

再帰関数を使って書く。
```py
class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        """
        再帰関数で解く
        """
        result = []
        def make_combination(combination, index, total):
            if total > target:
                return
            if total == target:
                result.append(combination[:])
                return
            for i in range(index, len(candidates)):
                combination.append(candidates[i])
                make_combination(combination, i, total + candidates[i])
                combination.pop()
        make_combination([], 0, 0)
        return result
```
- 最初result.append(combination[:])のところの[:]を忘れた。
    -  resultに入れた後に、(再帰からでて)その時指してたのと同じものに対してpopしてしまう

2分木バージョン
```py
class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        """
        2分木で
        """
        combination_total_index = [([], 0, 0)] # combination, total, index
        result = []
        while combination_total_index:
            combination, total, index = combination_total_index.pop()
            if total > target:
                continue
            if total == target:
                result.append(combination)
                continue
            if index >= len(candidates):
                continue
            combination_total_index.append((combination + [candidates[index]],
                          total + candidates[index],
                          index))
            combination_total_index.append((combination,
                          total,
                          index + 1))
                    
        return result
```

```py
class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        combination_total_index = [([], 0, 0)]
        result = []
        while combination_total_index:
            combination, total, index = combination_total_index.pop()
            if total > target:
                continue
            if total == target:
                result.append(combination)
                continue
            for i in range(index, len(candidates)):
                combination_total_index.append((combination + [candidates[i]], 
                                                total + candidates[i],
                                                i))

        return result
```
