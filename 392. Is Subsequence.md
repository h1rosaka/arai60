# STEP 1 自力で解く。
- 最初に解いたとき、sやtが空文字の場合を考慮できておらず、"←ここ"と書いている行がなかったのでWAになった。
    ```py
    """
    tから何個か削ってsを作れますか
    sを1文字ずつ見て
        tの中からそれを探す
    sの最後の文字まで見つかったらTrue
    時間計算量は、O(N)。Nはtの文字の長さ。10^4程度なので、1秒かからず終わる想定

    """
    class Solution:
        def isSubsequence(self, s: str, t: str) -> bool: 
            if s == "":  # ←ここ
                return True　 # ←ここ
            min_usable_t_index = 0
            for s_index in range(len(s)):
                for t_index in range(min_usable_t_index, len(t)):
                    if s[s_index] != t[t_index]:
                        # tを使い果たした場合
                        if t_index == len(t) - 1:
                            return False
                        continue
                    # 見つかった場合
                    min_usable_t_index = t_index + 1
                    if s_index == len(s) - 1:
                        return True
                    break
            return False  # ←ここ
    ```

    ```py
    """
    Q.tから何個か削ってsを作れますか

    sの中の文字cを先頭から一文字ずつ探す
        探す場所はtのまだ見てない範囲
            見つかるまでtの次の文字へ進み続ける
                もし、tを使い切ってしまったら、False返す
            見つかったら、tの見てない範囲をそこより1つ右に狭めつつ、cの次の文字を探し始める
        もしtを使い切ってしまったら、False
    """
    class Solution:
        def isSubsequence(self, s: str, t: str) -> bool:
            min_t_index = 0
            for c in s:
                for i in range(min_t_index, len(t)):
                    if t[i] == c:
                        break
                else:
                    return False
                min_t_index = i + 1
            return True

    ```

# STEP3　　3回連続でエラーなしで解けるまで解く
- 1番シンプルに感じたものを採用
    ```py
    """
    Q.tから何個か削ってsを作れますか

    t,s両方先頭から見て、両者が同じなら両ポインタを進める。違う場合は、t(削る方)だけ進める。
    sかtのポインタが範囲外になったら終了
    sのポインタが範囲外になってれば、sは全部見つかったということなので、True
    """
    class Solution:
        def isSubsequence(self, s: str, t: str) -> bool:
            t_index = 0
            s_index = 0

            while t_index < len(t) and s_index < len(s):
                if t[t_index] == s[s_index]:
                    t_index += 1
                    s_index += 1
                else:
                    t_index += 1

            return s_index == len(s)

    ```
