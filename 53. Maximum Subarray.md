# 問題タイトル
[53. Maximum Subarray](https://leetcode.com/problems/maximum-subarray/description/)



# STEP 1 自力で解く。
```py
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        index_to_largest_sum = [0] * len(nums)
        previous_sum = 0
        for i in range(len(nums)):
            if previous_sum < 0:
                index_to_largest_sum[i] = nums[i]
            else:
                index_to_largest_sum[i] = previous_sum + nums[i]
            previous_sum = index_to_largest_sum[i]
        return max(index_to_largest_sum)
```
- 6分ほどで解けた。
- 日記をつけるイメージ
- ある日の記録は下記２パターン
    - 1.前の日が負だった
        - 前の日までは考慮しない方が得なので、今日の記録がそのまま最大値
    - 2.前の日が0以上だった
        - 前の日の値と今日の記録を足したものが最大値

累積和
```py
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:  
        prefix_sum = 0
        min_prefix_sum = 0
        max_sum = -math.inf
        for num in nums:
            prefix_sum += num
            max_sum = max(max_sum, prefix_sum - min_prefix_sum)
            min_prefix_sum = min(min_prefix_sum, prefix_sum)
        return max_sum
```

# STEP3　　3回連続でエラーなしで解けるまで解く
```py
class Solution:
    def maxSubArray(self, nums: List[int]) -> int: 
        largest_sum = -math.inf
        prev_sum = 0
        for i in range(len(nums)):
            if prev_sum < 0:
                largest_sum_at_i = nums[i]
            else:
                largest_sum_at_i = nums[i] + prev_sum
            largest_sum = max(largest_sum, largest_sum_at_i)
            prev_sum = largest_sum_at_i
        return largest_sum
```
- max(previous_sum + nums[i], nums[i])とする解法も見たが、自分でやったり人に頼むときに、「足してみてから大きい方採用」とはやらない気がしたので、if文で分岐のままにした。
