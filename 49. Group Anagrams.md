# STEP 1 自力で解く。

```py
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        # prepare dictionary
        sorted_word_to_anagrams = dict()
        # loop for strs
        for str_ in strs:
            # sort and add to the dictionary
            sorted_str = str(sorted(str_))
            sorted_word_to_anagrams.setdefault(sorted_str, [])
            sorted_word_to_anagrams[sorted_str] += [str_]
        # return values of the dictionary
        return list(sorted_word_to_anagrams.values())
```

    class defaultdict(dict):
        def __init__(self, default_factory=None, *args, **kwargs):
            super().__init__(*args, **kwargs)
            self.default_factory = default_factory

        def __missing__(self, key):
            if self.default_factory is None:
                raise KeyError(key)
            else:
                self[key] = value = self.default_factory()
                return value

    ```

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        # prepare dictionary
        sorted_word_to_anagrams = defaultdict(list)

        for str_ in strs:

```

ord使いつつ、a~zであることのバリデーションする版
```py
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        def character_counter(str_):
            counter = [0] * 26
            for c in str_:
                if not ('a' <= c <= 'z'):
                    raise ValueError(f"Invalid character '{c}' found")
                counter[ord(c) - ord('a')] += 1
            return tuple(counter)

        counter_to_anagram = defaultdict(list)
        for str_ in strs:
            counter = character_counter(str_)
            counter_to_anagram[counter].append(str_)
        
        return list(counter_to_anagram.values())

```
- string.ascii_lowercase は、'abcdefghijklmnopqrstuvwxyz'を出してくれるので、それを使う手もある。

# STEP3　　3回連続でエラーなしで解けるまで解く

```py
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        sorted_to_anagrams = defaultdict(list)

        for str_ in strs:
            sorted_str = "".join(sorted(str_))
            sorted_to_anagrams[sorted_str].append(str_)

        return list(sorted_to_anagrams.values())
```

2:58, 2:29, 2:13
- 時間計算量: O(n * k log k)
    - O(n * k log k)
        - n 回　ループ
            - 1回あたり　klogk
                - 文字の長さがkのとき、ソートにO(klogk)
                - joinはO(k) 
                - append()はO(1)
    - O(n)
        - values()はO(1)
        - listの変換はO(n)

- 空間計算量: O(n*k)
    - sorted_to_anagrams: O(n*k)
        - key: O(n*k)。n個のキー。一つ一つは長さk
        - value:O(n*k)。 全体としては、n個の長さ平均kの単語が入っているので。
    - sort: O(k)
    - sorted_str: O(k)
    - list(sorted_to_anagrams.values()): sorted_to_anagramsと同じでO(n*k)
