# STEP 1 自力で解く。
```py
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        if not nums:
            return None
        # 今回のノード作る
        center_index = len(nums) // 2
        center = nums[center_index]
        node = TreeNode(center)
        # 左右の部分木は再帰で返ってきたものをくっつける
        node.left = self.sortedArrayToBST(nums[:center_index])
        node.right = self.sortedArrayToBST(nums[center_index + 1 :])
        return node
```

- 所要時間　７分
- 「自分が最後の担当者だったとして、部下に何を返してもらってどう作業すると完了するか」で整理して解けた。この考え方がとても使いやすい。

```py
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        dummy_head = TreeNode(None)
        stack = [(nums, dummy_head, "left")]
        while stack:
            partial_nums, parent, direction = stack.pop()
            if not partial_nums:
                continue
            mid_index = len(partial_nums) // 2
            mid = partial_nums[mid_index]
            node = TreeNode(mid)
            if direction == "left":
                parent.left = node
            else:
                parent.right = node
            stack.append((partial_nums[:mid_index], node, "left"))
            stack.append((partial_nums[mid_index + 1:], node, "right"))
        return dummy_head.left

```

# STEP3　　3回連続でエラーなしで解けるまで解く
```py
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        if not nums:
            return
        mid_index = len(nums) // 2
        mid = nums[mid_index]
        node = TreeNode(mid)
        node.left = self.sortedArrayToBST(nums[:mid_index])
        node.right = self.sortedArrayToBST(nums[mid_index + 1:])
        return node
```
2:58, 1:55, 1:30

計算量
- 時間：O(NlogN)
    - nums[:mid_index]とnums[mid_index + 1:]は合わせるとO(N)
        - 3段目以降も、だいたいn個分コピーするので、O(N)
        - 段数はlogN
- 空間: 
    - 再帰の深さ分のスタックメモリ: O(NlogN)
    - numsを毎回作る。左の部分木を作り続けている間、右はN/2のまま上書きされずに残る
        - 一番深くまで行った時：　N/2 + N/4 + ... = N

- 時間、空間ともにコピーによる無駄が多い。ヘルパーでleft, rightとってnumsは共有して使えばコピーしなくて済んだのでお得だった。
