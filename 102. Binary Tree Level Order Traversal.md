# 問題タイトル
[102. Binary Tree Level Order Traversal](https://leetcode.com/problems/binary-tree-level-order-traversal/)



# STEP 1 自力で解く。
```py
class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        # BFSでいく(段ごとに見たいので)
        # 段ごとにリスト作って、段の中が全部Noneになってたら、終了
        level_order_vals = []
        nodes = [root]
        while nodes:
            vals_of_this_order = []
            next_order_nodes = []
            for node in nodes:     
                if node is None:
                    continue
                vals_of_this_order.append(node.val)
                next_order_nodes.append(node.left)
                next_order_nodes.append(node.right)
            nodes = next_order_nodes
            if vals_of_this_order: # これなんとかしたいな 最後[]を足さない対策で入れている。
                level_order_vals.append(vals_of_this_order)

        return level_order_vals

```
- コメント
    - 最後[]が無駄に足されない異様にif文を追加しているが、なんかもっと上手くできそう
    - 段ごとにリスト作ってすり替えて、というBFSの書き方は普段あまりせず、段数も一緒に入れてしまう書き方をよくしていたが、今回練習になってよかった。

# STEP2 読みやすくする＆他の人の解法を見る

STEP1で無駄にNoneを格納していたのをやめ、シンプルにした。
```py
class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if root is None:
            return []
        level_order_vals = []
        nodes = [root]
        while nodes:
            vals_of_this_order = []
            next_order_nodes = []
            for node in nodes:
                vals_of_this_order.append(node.val)
                for child in [node.left, node.right]:
                    if child:
                        next_order_nodes.append(child)
            level_order_vals.append(vals_of_this_order)
            nodes = next_order_nodes

        return level_order_vals
```

listが複数入っていることがわかりやすい名前にして、levelとの大小比較が何をしているのかわかりやすくなることを狙った。
```py
class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        def order_nodes_by_level(node, level):
            if len(node_lists_ordered_by_level) < level:
                node_lists_ordered_by_level.append([])
            node_lists_ordered_by_level[level - 1].append(node.val)
            if node.left:
                order_nodes_by_level(node.left, level + 1)
            if node.right:
                order_nodes_by_level(node.right, level + 1)

        if root is None:
            return []
        node_lists_ordered_by_level = []
        order_nodes_by_level(root, 1)
        return node_lists_ordered_by_level

```

# STEP3　　3回連続でエラーなしで解けるまで解く

```py
class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if root is None:
            return []
        nodes_in_this_level = [root]
        ans = []
        while nodes_in_this_level:
            node_vals = []
            next_nodes = []
            for node in nodes_in_this_level:
                node_vals.append(node.val)
                if node.left:
                    next_nodes.append(node.left)
                if node.right:
                    next_nodes.append(node.right)
            ans.append(node_vals)
            nodes_in_this_level = next_nodes
        return ans
```
2:48, 2:20, 2:35
- 中々3回連続クリアできなかったので色々と変えた。
    - 変数名の変更
        - nodeとnodesの空目/typo対策
        - level_order_traversalをansに
    - child方式の廃止
        - nodeごとにやるべき仕事が3つあることをクリアに。ネスト浅くして全体の見通しをよく。

- 計算量
    - 時間：O(N)
        - 全てのノードを一度ずつ処理。1度の処理にO(1)の操作のみ
    - 空間: O(N)
        - nodes_in_this_level:O(N)
            - 綺麗に埋まった二分木だと、最後の層で最大 約 N/2 個入る
        - node_vals: nodes_in_this_levelと同じオーダー
        - next_nodes: nodes_in_this_levelと同じオーダー
        - ans: O(N)
